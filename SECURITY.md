# Security Policy

This is an educational project, maintained on a best-effort basis. Security
reports are welcome and taken seriously.

## Supported Versions

The `main` branch is the supported version; older commits are not maintained.
There is no hosted service: the tool drives a local Chrome browser, so the main
risks lie in its dependencies and in the environment it is run in.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please **do not open a
public issue**.

Instead, contact the maintainer privately and include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fixes or mitigation ideas

This project is a demonstration and is not covered by a service-level agreement,
so response times are best-effort.
